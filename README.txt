CHannak Bill Invoice Pro
========================
Android offline billing app for VIKAS ENTERPRISES.

Open this folder in Android Studio.
Then: Build > Make Project
Then: Build > Build APK(s)

Package: com.channak.billinvoicepro

Main features:
- Offline invoice entry
- Qty x Rate calculation
- Subtotal and amount in words
- Invoice history
- A4 PDF generation and sharing
- Bank details and Terms & Conditions
- VIKAS ENTERPRISES invoice layout

Note: For Android 7+ file-sharing providers may require a FileProvider for production distribution.
This starter uses the Android environment available in the project and is intended for Android Studio build/testing.
